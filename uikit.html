12 — Dev

Экспорт токенов

Готовые файлы для сайта, Figma-плагинов и design tokens pipeline.

tokens.css

CSS-переменные + utility-классы (.btn-primary, .text-h1, .container). Подключить на любом HTML-странице.

Скачать tokens.css

tokens.json

Design Tokens Format — цвета, типографика, spacing, кнопки, логотип. Для Figma Tokens, Style Dictionary, Tailwind.

Скачать tokens.json

Подключение на сайте

<!-- fonts + tokens --> <link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Inter:wght@400;600;700&display=swap"> <link rel="stylesheet" href="tokens.css"> <!-- пример использования --> <h1 class="text-h1">IntegraSystem</h1> <a class="btn-primary" href="#">Наши решения</a> <div class="container">...</div>

CSS-переменные

/* цвета */ color: var(--integra-blue); background: var(--deep-black); /* типографика */ font-size: var(--font-size-h2); font-family: var(--font-family); /* spacing */ padding: var(--space-5); max-width: var(--max-width);
